# 口論ゲーム (Argument Typing Game)

タイピングの速さと正確さで相手を論破する、爽快タイピングバトルゲームです。

**URL:** [https://huageheize-star.github.io/my-app-2026/](https://huageheize-star.github.io/my-app-2026/)

---

## 🎮 ゲーム概要

次々と繰り出される相手の理不尽な言葉に対し、適切な反論を素早くタイピングして「論破」しましょう！相手のHPをゼロにすれば勝利、自分のHPがなくなると敗北です。

## 🕹 遊び方

1. **対戦相手を選択**: タイトル画面で対戦したい相手を選びます。
2. **反論をタイピング**: 相手の発言が表示されたら、画面下部の「反論」テキストに合わせてローマ字でタイピングします。
3. **制限時間に注意**: 画面中央のタイムバーがなくなるとダメージを受けます。
4. **ミスは禁物**: タイピングをミスすると自分のHPが少しずつ減少します。正確に打ちましょう。

## ✨ 特徴

- **柔軟な入力判定**: `shi` と `si`、`chi` と `ti`、`fu` と `hu` など、複数のローマ字入力方式を自動で受け付けます。
- **コンボシステム**: ミスをせずに打ち続けるとコンボが繋がり、バトルを盛り上げます。
- **臨場感のある演出**: 
  - ダメージを受けると画面が揺れ、背景が赤く変化します。
  - Web Audio APIによる、外部ファイル不要のブラウザ生成SEを搭載。
- **個性豊かな対戦相手**: 難易度別に4人のキャラクターが登場します。

## 👥 対戦相手紹介

- **Level 1: なまいきな弟 (👦)** - 難易度：低
  - かわいい悪口を繰り出してきます。まずはここから。
- **Level 2: オコリンボな母 (👩)** - 難易度：中
  - 日常生活の小言を素早く論破しましょう。
- **Level 3: 理詰めな恋人 (👱‍♀️)** - 難易度：高
  - ちょっとした矛盾も見逃してくれません。
- **Level 4: 鬼の教授 (👨‍🏫)** - 難易度：極
  - 圧倒的な論理的威圧。最速のタイピングが求められます。
